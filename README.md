# Codveda Technologies Data Science Internship

This repository contains the completed multi-level tasks for the Codveda Technologies internship, focusing on data analysis, predictive machine learning, and natural language processing. 

### Tools & Libraries
* Python, Jupyter Notebook
* Pandas, Matplotlib, Seaborn
* Scikit-Learn (Linear Regression, Logistic Regression, Random Forest, GridSearchCV)
* WordCloud, TF-IDF

### Project Structure

**Level 1 & Level 2: Data Preprocessing & Regression**
* `Task1&2.ipynb` / `Lvl2_Task1.ipynb`: Data cleaning, handling custom delimiters, and resolving missing values.
* `Lvl2_Task3.ipynb`: Implementation of a Simple Linear Regression model to predict housing prices.

**Level 3: Advanced Machine Learning**
* `Lvl3_Task1.ipynb`: Predictive Classification modeling (Logistic Regression & Random Forest) to analyze customer churn, including feature scaling and Grid Search tuning.
* `Lvl3_Tasl3.ipynb`: Natural Language Processing (NLP) pipeline generating a sentiment word cloud and training a Naive Bayes text classifier.
